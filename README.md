# 📝 Java Swing Notepad Application

A simple but powerful **Notepad-like desktop application** built using **Java Swing**.  
This project demonstrates core concepts of GUI development, event handling, and real-time text processing in Java.

---

## 🚀 Features

### 📄 File Operations
- Create new file
- Open existing file
- Save file
- Save As
- Exit application

### ✏️ Text Editing
- Undo / Redo functionality
- Real-time typing support
- Keyboard shortcuts support

### 🔤 Formatting Tools
- Change font (Arial, Comic Sans MS, Times New Roman)
- Change font size (8 to 28)
- Word Wrap ON/OFF

### 🎨 Color Themes
- White theme
- Black theme
- Blue theme

### 📊 Live Status Bar
- Real-time **word count**
- Real-time **character count**

### 🔍 Find Feature
- Search for words inside text
- Highlights all matching words
- Case-insensitive search

---

## 🧠 Key Concepts Used

- Java Swing (JFrame, JTextArea, JMenu, JLabel)
- Event Handling (ActionListener, KeyListener)
- DocumentListener (real-time text tracking)
- UndoManager (undo/redo system)
- String processing (word counting, searching)
- GUI layout management (BorderLayout, JScrollPane)
